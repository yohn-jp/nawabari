# Nawabari 0.12.2

Nawabari 0.12.2 supersedes the failed 0.12.1 npm publication attempt and preserves the 0.12 runtime feature set unchanged.

## Release fix

The 0.12.1 publish workflow reached the packed smoke job with the protected-execution runtime prerequisites installed, but the smoke script imports source-side compiled modules from `dist/`. That job had not run the build step, so it failed with `ERR_MODULE_NOT_FOUND` for `dist/domain/sandbox.js`.

0.12.2 fixes the release workflow by building the source-side smoke dependencies before executing the validated tarball smoke test.

## Compatibility

No product semantics change relative to 0.12.1. Node.js 24 or newer remains required. Protected session execution remains Linux-only and fail-closed when required sandbox/runtime capabilities are unavailable.

## Upgrade

```bash
npm install -g nawabari@0.12.2
npx -y nawabari@0.12.2 --version --json
```

## Release verification

The release path verifies the immutable `v0.12.2` tag against `package.json`, builds and validates the exact publish tarball, provisions protected-execution prerequisites, builds source-side smoke dependencies, smoke-tests the validated artifact, and publishes through npm Trusted Publishing/OIDC.
