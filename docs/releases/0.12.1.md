# Nawabari 0.12.1

Nawabari 0.12.1 supersedes the failed 0.12.0 npm publication attempt and includes the complete repository-governed local runtime and observability release.

## Highlights

- Completes multi-session resource coordination, runtime profiles, governed filesystem policy, and worktree-local protected execution.
- Adds the canonical Repository Runtime Snapshot and bounded agent/UI observability projections.
- Adds bounded lifecycle/execution history with provenance while keeping history strictly non-authorizing.
- Strengthens composed Linux/Nix/package certification across the complete runtime path.
- Fixes npm release validation so packed protected-runtime certification receives the same required Linux runtime prerequisites as CI.

## Release recovery

The GitHub `v0.12.0` release is immutable and its npm publication failed before publish because the release workflow lacked the protected-execution runtime prerequisites required by the packed certification.

0.12.1 is a new release. It does not rewrite or reuse the `v0.12.0` tag.

## Compatibility

This is a pre-1.0 patch release over the 0.12.0 source line. Node.js 24 or newer remains required. Protected session execution remains Linux-only and fail-closed when required sandbox/runtime capabilities are unavailable.

## Upgrade

```bash
npm install -g nawabari@0.12.1
npx -y nawabari@0.12.1 --version --json
```

## Release verification

The release path verifies the immutable `v0.12.1` tag against `package.json`, builds and validates the exact publish tarball with the required protected-execution prerequisites, smoke-tests that artifact, and publishes through npm Trusted Publishing/OIDC.
