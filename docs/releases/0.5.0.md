# nawabari 0.5.0

## Summary

Nawabari 0.5.0 strengthens the standalone session lifecycle and the machine contract used by external orchestrators. It adds deterministic worktree placement control, safe cleanup after squash/rebase integration, side-effect-free close readiness inspection, actionable lifecycle diagnostics, and hermetic repository-owned verification.

## Highlights

- `session create --worktree-root <path>` lets callers choose the managed worktree parent while Nawabari remains authoritative for the final worktree identity.
- `session close --integrated-revision <rev>` safely handles squash/rebase/non-ancestry integration by independently proving exact Git tree-object equivalence before destructive cleanup.
- `session inspect [--integrated-revision <rev>]` exposes bounded, side-effect-free close/cleanup readiness with stable blockers, safe actions, claims, and integration evidence.
- Lifecycle and ownership rejections such as `RESOURCE_CLAIM_CONFLICT`, `PROTECTED_WORKTREE`, invalid session identity, and `RECOVERABLE_COMMITS` now include bounded machine-readable context and deterministic recovery guidance.
- Required `pnpm test` / `pnpm verify` verification is hermetic and repository-owned; controlled sandbox-launcher contract tests no longer require privileged machine-global fixture installation. Real bubblewrap isolation evidence remains a separate capability-gated conformance class.

## Compatibility

This is a pre-1.0 minor release with additive CLI and machine-contract surface. Existing 0.4.x session state does not require migration for these changes. Ordinary ancestry-based session close remains the default path; non-ancestry integration evidence is explicit and independently verified by Nawabari.

Nawabari remains standalone: it does not query GitHub, Mottainai, or gh-inari to decide whether physical cleanup is safe. External orchestrators may provide an integrated local revision, but Nawabari remains the fail-closed physical authority.

## Upgrade

```bash
npm install -g nawabari@0.5.0
npx -y nawabari@0.5.0 --version --json
npx -y nawabari@0.5.0 capabilities --json
npx -y nawabari@0.5.0 session inspect --help
```
