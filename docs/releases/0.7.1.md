# Nawabari 0.7.1

Nawabari 0.7.1 publishes the resource-ownership lifecycle improvements merged after 0.7.0.

## Highlights

- Selected-resource release and explicit all-claims release through the public CLI.
- Deterministic exact-resource transition recovery with authoritative claim-set generation for CAS.
- Versioned resource-claim machine contract (`nawabari.resource-claims.v2`) with packed public lifecycle coverage.
- Packed lifecycle coverage for acquire -> transition -> atomic adjust -> selected release -> complete replacement -> safe recovery without raw registry manipulation.

## Compatibility

This is a patch release. It introduces no additional breaking migration beyond the 0.7.0 claim-concurrency contract.

## Known remaining conformance work

Issue #165 remains open. Independent conformance work is still required around advertised failure-code reachability, public-output/result-schema validation, operation-specific authority-rationale projection, command/alias identity parity, and downstream evidence posting.
