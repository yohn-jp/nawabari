# Nawabari 0.10.2

Nawabari 0.10.2 is a patch release with CLI/session UX and runtime materialization fixes.

## Fixes

- Round up CLI and session UX consistency (#331).
- Make strict runtime materialization succeed by default (#329).
- Project minimal Git author identity into sandboxed commits (#325, #330).
- Fix README quickstart's failing first command (#328).

No breaking changes.

## Upgrade

```bash
npm install -g nawabari@0.10.2
npx -y nawabari@0.10.2 --version --json
```
