# Nawabari 0.10.1

Nawabari 0.10.1 is a release-pipeline fix. The 0.10.0 publish run failed in CI before it could build or publish a package; no 0.10.0 artifact was ever published to npm.

## Fix

- `publish.yml`'s build job checks out the release tag's own workflow definitions into a nested `.workflow-source/` directory to verify the pinned workflow matches what is running. That directory was not excluded from formatting checks, so `pnpm run format:check` (`prettier --check .`) recursed into it and failed on files that are byte-synchronized from the `yohn-jp/.github` authority repository and intentionally use its formatter profile.
- Added `.workflow-source/` to `.prettierignore` and `.gitignore` so the self-verification checkout no longer participates in source formatting checks.

No CLI behavior, runtime projection, or protected-execution semantics changed in this release.

## Upgrade

```bash
npm install -g nawabari@0.10.1
npx -y nawabari@0.10.1 --version --json
```
