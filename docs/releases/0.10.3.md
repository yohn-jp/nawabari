# Nawabari 0.10.3

Nawabari 0.10.3 is a patch release with Git identity and runtime materialization fixes.

## Fixes

- Project host Git identity into managed commits (#336).
- Make strict runtime materialization independent of pnpm (#337).
- Condense doctor and deduplicate inspect lifecycle (#338).

No breaking changes.

## Upgrade

```bash
npm install -g nawabari@0.10.3
npx -y nawabari@0.10.3 --version --json
```
