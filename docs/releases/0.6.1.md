# Nawabari 0.6.1

Nawabari 0.6.1 closes the remaining integration-proof gap exposed by Mottainai's end-to-end Golden Path.

## Highlights

- `session close` can explicitly obtain a missing merged integration revision from one named Git remote branch with `--fetch-remote` and `--fetch-branch`.
- The fetch is opt-in only, targets a disposable internal proof ref, does not update tracking refs or `FETCH_HEAD`, and does not call provider APIs.
- The supplied full merge SHA is still independently checked against the fetched integration lineage and existing ancestry/tree-equivalence safety before cleanup.
- Remote-tip races, invalid remote/branch inputs, fetch failures, dirty worktrees, recoverable commits, and identity mismatches continue to fail closed.
- Organization-managed governance scripts are synchronized to their canonical formatting so required CI is green again.

## Compatibility

This is an additive patch release. Existing local-only close behavior is unchanged when the explicit fetch options are absent. No registry migration is required.
