# nawabari 0.4.1

## Summary

Nawabari 0.4.1 is the publishable 0.4-series release from the current green main. It supersedes the npm publication attempt for 0.4.0 and includes the release/CI hardening merged after that tag.

## Highlights

- Protected Linux session execution with fail-closed sandbox capability handling.
- Atomic complete-set resource claim replacement through `session update` / `resource update`.
- Outcome-aware registry durability and reconciliation.
- Deterministic sandbox-launcher test capability shared by CI and release publication paths.
- Release workflow validation and a corrected normal publication path.

## Compatibility

No migration is required from 0.3.x state. The 0.4.1 product contract is the 0.4-series contract described in the 0.4.0 release notes, plus release/CI correctness fixes merged on main.

## Upgrade

```bash
npm install -g nawabari@0.4.1
npx -y nawabari@0.4.1 --version --json
npx -y nawabari@0.4.1 capabilities --json
```
