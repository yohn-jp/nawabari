# nawabari 0.2.0

## Summary

This release completes Nawabari's standalone local repository execution
authority described by Issue #29. It ships the versioned
`nawabari.standalone-execution.v1` machine contract in `nawabari@0.2.0`.

## Highlights

- **Standalone execution authority**: Nawabari owns session, repository,
  worktree, branch, resource-claim, authorization, mutation, evidence, and
  conservative cleanup lifecycles without Mottainai, GitHub, `gh`, or network
  runtime dependencies.
- **Versioned machine contract**: the installed CLI exposes
  `nawabari.standalone-execution.v1` through `capabilities --json` and
  `--version --json`.
- **Claim-governed execution**: repository-relative resource claims,
  operation authorization, Git-observable checkpoint evidence, governed local
  commit/push, drift diagnostics, and concurrency/fault-safe lifecycle
  behavior are available in the packed artifact.
- **Release integrity**: the exact `npm pack` tarball is validated, installed
  in isolation, and exercised through the installed CLI before publication.

## Upgrade

```bash
npm install -g nawabari@0.2.0
npx -y nawabari@0.2.0 capabilities --json
```

Mottainai remains an optional orchestrator. It must consume this standalone
contract rather than maintain a duplicate local execution authority.
